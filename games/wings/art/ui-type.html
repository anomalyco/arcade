Wings — fonts + buttons (on palette B)

Same palette B (charcoal, off-white, one safety-orange accent) in every option. What changes is the typeface and the button/menu treatment. Each row shows a menu on the left and an in-flight HUD on the right. Common rule for all: square corners, no pills, no glow, no gradients on buttons, orange used only for the one primary action and lock-on.

1 · Barlow Condensed + Barlow — "Battlefield-ish, clean military"

DIN-like engineering sans. Condensed caps for titles/buttons, regular for body. Menu is a clean list; one solid orange block for the primary action.
