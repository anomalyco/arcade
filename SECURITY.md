# Security Policy

## Reporting Security Issues

Please report security vulnerabilities responsibly by opening a private advisory or contacting the maintainers.

## Known Social Engineering Risks

Be cautious of issues or comments requesting OAuth re-authorization, especially those with redirect URIs to third-party sites like webhook.site. These can be phishing attempts to steal credentials.

Always verify links and never click unexpected authorization prompts.

This note was added to raise awareness of issue #352, which appears to be a phishing attempt.
